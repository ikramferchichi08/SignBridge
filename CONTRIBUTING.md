# Contributing

## Branches

Use `feat/<short-description>` for features and `fix/<short-description>` for
bug fixes. Do not commit directly to `main`.

## Pull requests

Open a pull request into `main` when the branch is ready. The teammate must
provide at least one review. Resolve review comments, run the relevant tests,
and squash-merge the pull request.

## Commits

Use clear Conventional Commits, for example:

```text
feat: add landmark normalization
fix: handle missing hand landmarks
chore: pin project dependencies
docs: describe DVC remote setup
test: add MLflow smoke test
```
